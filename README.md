# 小黑陪你

一个给 Kali 的独立宠物应用，主要面向 iPhone。以和小狗相处为中心，包含照顾、玩球和握手小课堂。支持添加到主屏幕，以独立窗口启动。

## 使用

在 iPhone 上用 Safari 打开 https://ziyangshen0510-star.github.io/Freddy/pet/ ，点「分享 → 添加到主屏幕」。已在线打开并缓存成功后可以离线使用。

- 小狗使用实际三维关节动画，会眨眼、呼吸、摇尾巴和散步。
- 可以按住小狗抚摸，或用下方按钮照顾它；点碗会走过去吃东西，抛球会追过去、叼回来。
- 睡觉可中断其他动作。照顾结果在完成动作后才记入状态，不会因连点而重复获得。
- 音效初次默认关闭，可在右上角打开，之后会记住开关选择。尊重系统「减少动态效果」设置。
- 名字、状态和相处记录只保存在当前浏览器。清除网站数据、换设备或更换浏览器会重新开始；没有账号、上传或统计。
- 「布置小窝」可搭配三种房间色调、地毯和摆件。可以先试选，不保存退出会恢复原样；保存后下次重开保留，装饰不影响成长记录。
- 问候会跟随本地时间变化，陪伴文案偶尔轮换。小狗正忙或装扮窗口打开时，不用闲聊覆盖当前反馈。
- v6 使用更清晰的双栏 / 手机布局，增加窗帘、书架、柔和窗光、陪伴日记和亲密状态。照顾按钮显示正在进行的动作，房间下方可直接更换布置。
- 最近 12 条相处记录会留在本地，默认显示 3 条，点「多看一点」可展开；升级保留原有存档中仍存在的记录。
- v7 新增「今日小心愿」：摸摸、玩球、练习握手各一次，完成后可领取一份小礼物。文案和完成状态按本地日期更新，没有连续签到惩罚，隔几天回来，已经获得的成长仍在。
- 「握手小课堂」里，光点进入绿色时伸手，可得到额外默契反馈；没有接准也能温柔地完成练习。尊重减少动态效果，键盘也能操作。小狗实际抬起前爪，动作完成后才记下练习次数。
- 每次照顾积累默契与成长等级，纪念册可查看 8 种纪念章和握手熟练度。相同动作一天内第 6 次起只有少量成长，鼓励多种互动。
- 累计领取 1 / 3 / 7 份心愿礼物分别得到蜜桃粉 / 晴空蓝 / 暖阳金领巾，在纪念册衣橱切换；支持三维渲染时会直接改变小狗的领巾颜色。礼物不要求连续日期。
- 精力较低时仍能玩一轮温柔慢跑版追球，避免回访后被长时间休息挡住。滑动页面离开小窝，也会把正在进行的照顾动作和睡姿过渡完成。
- 成长使用独立的 `kali-puppy-journey-v1` 本地存档，不改写原有小狗和房间存档；损坏或不可用的浏览器存储不会阻止当前页面继续玩。
- 不会因为离开太久而死亡或失去宠物，没有签到要求。

这是可安装的网页应用（PWA），不是 App Store 安装包，也不能悬浮在其他 App 上。系统不支持三维渲染时使用轻量外观，照顾功能仍可使用。

## 本地开发

Node.js 18+，服务端无需安装依赖，三维运行脚本已随仓库携带：

```sh
npm start
npm run check
```

默认端口为 3000，可用 `PORT` 更改。根地址会直接进入宠物应用。

三维源代码在 `pet/puppy-world.js`，改动后运行 `npm run build:puppy` 重新生成 `pet/puppy-world.bundle.js`。此构建命令使用固定版本 esbuild 0.25.5。Three.js 0.187.0 的源码和 MIT 许可证位于 `pet/vendor/`，下载来源及 SHA-512 记录在 `pet/vendor/version.json`。

修改客户端后需同步更新 HTML 中的资源版本和 `pet/sw.js` 的缓存版本，保留 `kali-little-dog-v1` 存档键。

## 独立离线文件

```sh
python3 scripts/export-offline.py
```

生成 checkout 旁 `Freddy-deliverables/Little-Black-Offline.html`。图片、三维脚本与界面均在一个文件中，适合电脑浏览器离线打开。文件版无法添加为 iPhone 主屏幕 PWA；手机请用上面的 HTTPS 网址。

## 发布

静态文件已配置发布到此仓库的 `gh-pages` 分支，GitHub Pages 会自动构建。推送成功不等于部署成功；应检查 GitHub Actions 的 Pages 发布任务。

逐步改进记录与后续计划见 [UPGRADE_PLAN.md](docs/UPGRADE_PLAN.md)。目前没有配置后台每日自动升级。

## 回归验证

需要 Python Playwright 和 `/usr/bin/chromium`：

```sh
python3 tests/verify_pet.py
python3 tests/verify_room.py
python3 tests/verify_refinement.py
node tests/verify_journey.cjs
python3 tests/verify_journey_ui.py
```

覆盖每日心愿、礼物去重、成长与穿搭、握手小游戏与真实抬爪、跨日 / 离屏 / 存储异常，以及三维互动、离线升级与旧存档、装饰保存 / 取消、音效偏好、记录展开、存储不可用，以及 320–1440px 布局。浏览器仿真不等于 iPhone 真机验证。
