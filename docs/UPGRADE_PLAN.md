# 小黑的渐进改进记录

每次只改一两个重点，验证后更新同一个网址，保留名字和成长存档。

当前聊天没有可用的定时任务服务，未设置后台自动升级。用户回来继续对话时，再从下面的计划接着做；不要把每天随机改变参数或运行一次构建称为模型升级。

## v4：轮廓与连续动作

- 调整肩膀和后腿体积，让四肢从上到下逐渐收细，减少拼接关节感。
- 用实际前进距离控制脚步，缓冲起步与停步，慢走采用四拍脚步。
- 按真实帧间隔平滑转向，走最短转角，并限制转身速度。
- 尾巴保持连续摆动相位，耳朵、头部和嘴巴柔和过渡。
- 身体轻微起伏留在躯干，不再让整只狗一起离地。

## 紧接着的任务

用户要求完成以上动作优化后，再做：偶尔变化的小文案，以及可保存的房间装饰选择。

## 后续可逐步改进

1. 更贴近真实拉布拉多的头颈连接、口鼻和耳朵轮廓。
2. 转弯时更稳的世界坐标落脚点，进一步减少滑步。
3. 耳朵与尾巴的惯性、抖毛、伸懒腰等独立小动作。
4. 更细腻的短毛与布料质感，并持续控制 iPhone 的渲染开销。

每次更新都要检查抚摸、喂食、追球、睡觉中断、旧存档升级、离线启动和减少动态效果设置。不能宣称未经真机验证的 iPhone 性能。
