# 小黑的渐进改进记录

每次只改一两个重点，验证后更新同一个网址，保留名字和成长存档。

当前聊天没有可用的定时任务服务，未设置后台自动升级。用户回来继续对话时，再从下面的计划接着做；不要把每天随机改变参数或运行一次构建称为模型升级。

## v4：轮廓与连续动作

- 调整肩膀和后腿体积，让四肢从上到下逐渐收细，减少拼接关节感。
- 用实际前进距离控制脚步，缓冲起步与停步，慢走采用四拍脚步。
- 按真实帧间隔平滑转向，走最短转角，并限制转身速度。
- 尾巴保持连续摆动相位，耳朵、头部和嘴巴柔和过渡。
- 身体轻微起伏留在躯干，不再让整只狗一起离地。

## v5：小文案与可保存的房间装饰

- 问候随本地时间变化，陪伴卡片与空闲时的小话语定期轮换，保持喂食、追球等反馈完整。
- 玩家可以搭配房间色调、地毯和摆件，取消会回到保存过的样子。
- 房间布置使用独立存储，不影响小狗的名字和成长记录。

## v6：温暖的小窝与照顾细节

- 重做奶油绿界面、双栏布局和手机排版，保留原来的三维小狗与所有照顾动作。
- 房间增加窗帘、书架、小花瓶、窗光和踢脚线；装饰主题仍可预览、保存或取消。
- 增加本地日期、陪伴日记章、亲密状态与照顾提示，按钮显示当前正在进行的动作。
- 新增房间下方的布置入口，取消后返回原入口；Escape 立即恢复已保存的布置。
- 音效开关可保存；相处记录从最近 3 条扩展为最近 12 条，默认折叠显示。过去已被旧版本移除的记录无法恢复。
- 同步更新离线缓存到 v6，继续使用原有宠物和房间存档键。
- 已用 Chromium 检查互动、离线与升级、装饰、偏好保存、受限存储和 320–1440px 布局，未作 iPhone 真机性能结论。

## 后续可逐步改进

1. 更贴近真实拉布拉多的头颈连接、口鼻和耳朵轮廓。
2. 转弯时更稳的世界坐标落脚点，进一步减少滑步。
3. 耳朵与尾巴的惯性、抖毛、伸懒腰等独立小动作。
4. 更细腻的短毛与布料质感，并持续控制 iPhone 的渲染开销。

每次更新都要检查抚摸、喂食、追球、睡觉中断、旧存档升级、离线启动和减少动态效果设置。不能宣称未经真机验证的 iPhone 性能。
